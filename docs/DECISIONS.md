### 第一轮（2026-08-16，grilling 产出）

| # | 决策点 | 结论 |
|---|---|---|
| 1 | 底座路径 | **摘取重组**：新建干净项目（backend/ + frontend/），从 Project Lunar 摘取思想（记忆金字塔、NPC 私有心智、事件溯源、信息隔离），orchestrator 按我们的极简循环重写。不 fork 原 3000 行核心类 |
| 2 | 部署边界 | **单机自用**：localhost、无鉴权、API Key 存后端（每世界配置、预填上次），同一时间玩一个世界 |
| 3 | 回步预算 | **同步 1 次 LLM**：主叙事一次返回正文+选项+元数据（时间/地点/在场NPC）；异步副作用（NPC 心智、记忆结晶、世界推进）走便宜模型，不阻塞 |
| 4 | 属性系统 | **轻数值**：属性进世界状态、抽屉可见可变、prompt 显式提示成败倾向；重要行动影响叙事裁决；不做掷骰/判定管线 |
| 5 | 选项生成 | **主叙事一次返回**：正文流式输出，结尾附结构化块（2~4 选项+元数据）；解析失败则本回合无选项（优雅降级，自由输入永远可用） |
| 6 | 中文策略 | **全中文 prompt**：所有系统 prompt 中文撰写，输出中文 |
| 7 | 世界推进 | **纯回合制**：只在玩家行动产生叙事时间跳跃时推进（World Reactor 分级），无离线推进、无后台实时模拟、不玩不花钱 |
| 8 | NPC 秘密 | **玩家视角**：抽屉只显示可感知信息（关系/表面情绪/公开身份）；goal/secret_plan 仅进 prompt |
| 9 | 模型 | **DeepSeek**（deepseek-chat），OpenAI 兼容协议；架构支持任意兼容端点 |
| 10 | 正文篇幅 | **自适应**：高频动作反应十几个字即抉择；叙事/对话/大推进可数百字。prompt 里写明规则 |

## 核心循环（唯一 orchestrator）

```
玩家行动 → 读世界状态 → 读记忆窗口 → 组装上下文（世界/NPC状态/记忆/主线压力/近期历史）
→ 主 LLM 调用（流式正文 + 结尾结构化块：choices/时间增量/地点/在场NPC）
→ 更新状态与事件库 → [异步·便宜模型] NPC 心智更新 / 属性变化 / 世界推进(时间跳跃≥1h) / 记忆结晶(每4事件)
→ 等待玩家
```

## 产品形态

- 首页：世界列表 + 创建新世界
- 创建页：模型配置（预填）+ 世界设定/规则/剧情基调（有默认模板）+ 玩家（姓名/身份/背景 + 属性默认50可改）+ 重要人物/初始关系（自由文本，创建时一次 LLM 解析成 NPC 卡）
- 游戏页：`时间·地点` 头部 + 剧情流（玩家行动与叙事交替）+ ①②③选项 + 自由输入；右侧三个抽屉：**角色 / 状态 / 世界**（玩家视角）
- V1 不做：战斗系统、地图、图谱、日志面板、物品标签、审计员、模式检测 LLM、rewind、多人、TTS、图片、插件
